🔑 2. 認証・認可システム

2.1 パスワードハッシュ

  • PBKDF2-SHA-256（10万回反復）を採用。NIST推奨基準を満たす。
  • 128bitランダムソルト生成。レインボーテーブル攻撃を防止。
  • レガシーSHA-256からの自動移行機構あり。ログイン成功時にPBKDF2へ置換。
  • タイミング攻撃対策：定数時間比較 timingSafeEqual() を実装。
  • bcryptとの併存対応（auth_usersテーブル用）。

2.2 JWTトークン

  • Hono組み込みの sign() / verify() を使用（HMAC-SHA256）。
  • JWT秘密鍵は環境変数 JWT_SECRET から取得。
  • フォールバック秘密鍵が存在：環境変数未設定時に固定文字列 INSECURE-FALLBACK-CHANGE-ME-IN-PRODUCTION を使用。本番で誤って使われると全トークンが偽造可能。
  • 有効期間が7日間：教育アプリとしては妥当だが、トークンの無効化（ログアウト時のブラックリスト）機構がない。

2.3 Cookie設定

  • httpOnly: true — JavaScriptからアクセス不可。
  • secure: true — HTTPS通信のみ。
  • sameSite: 'Strict' — CSRF対策として有効。

2.4 ログイン保護

  • ログイン失敗5回でアカウントロック（15分間）。
  • 残り試行回数をレスポンスで返却（ユーザービリティ配慮）。
  • ロック機構は /api/auth/login（第2系統）のみに実装。第1系統の login() 関数（auth.ts）にはロック機構がない。

2.5 ロールベースアクセス制御（RBAC）

  • 4つのロール定義：student, teacher, parent, admin
  • requireRole() / requireUserType() ミドルウェアが実装済み。
  • ミドルウェアの適用漏れが多数。後述のAPI項目参照。

3.5 SQLインジェクション対策

  • validateSQLParam() による追加検証関数あり。

🖥️ 4. フロントエンドセキュリティ

4.1 XSS（クロスサイトスクリプティング）

  • innerHTML の使用：775箇所。XSSの潜在リスクが非常に高い。
  • 安全な textContent の使用：223箇所（全体の22%のみ）。
  • DOMPurify等のサニタイズライブラリ未導入。
  • サーバーサイドに sanitizeInput() 関数あり（HTMLタグ除去、イベントハンドラ除去）。

現状ではDB内データが信頼されている前提で設計されていますが、悪意あるデータがDBに入った場合にXSSが発生する可能性があります。

4.3 CSP（Content Security Policy）の詳細

  • 'unsafe-inline' がscript-src・style-srcに設定。インラインスクリプト/スタイルが許可されるため、XSSの軽減効果が限定的。
  • 'unsafe-eval' がscript-srcに設定。eval()が許可される。
  • frame-ancestors 'none' でクリックジャッキングを防止。

4.4 機密データの露出

  • APIキーはサーバーサイドのみで使用（env.GEMINI_API_KEY）。フロントエンドに露出なし。
  • JWTトークンはhttpOnly Cookieに保存。JSからアクセス不可。
  • 答え漏洩防止：stripAnswerSections()、filterAnswerFromText()等でカード表示時に正解データを除去。
  • フロントエンドのlocalStorageに学習進捗（cardProgress）を保存。機密性は低いが改ざん可能。

🛡️ 5. データ保護・秘密情報管理

5.1 秘密情報管理

  • .dev.vars は .gitignore に含まれている。Gitに秘密情報がコミットされない。
  • 本番環境では wrangler pages secret put でCloudflare Secretsとして管理。
  • 管理対象：JWT_SECRET, GEMINI_API_KEY, CLOUDFLARE_API_TOKEN

5.2 データベースセキュリティ

  • Cloudflare D1（SQLite）使用。Cloudflareインフラで物理的に保護。
  • パスワードハッシュは pbkdf2:100000:salt:hash 形式で保存。平文パスワードは保存されない。
  • 個人情報（児童生徒の氏名・メールアドレス）は暗号化されずに保存。

5.3 通信セキュリティ

  • Cloudflare Pages でデフォルトHTTPS。TLS 1.2以上を強制。
  • HSTSヘッダー設定済み（max-age=1年、includeSubDomains、preload）。
