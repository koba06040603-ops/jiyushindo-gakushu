振り返り実践ガイド（松川中学校版）

— メタ認知を育てる5段階フレームと教科別の声かけ —

このガイドの位置づけ

生徒の学びを一段深くする鍵は、授業の終わりに書く「振り返り」にあります。 しかし「何となく書かせる」だけでは「楽しかった」「むずかしかった」で終わってしまい、 学力にも、自立した学習者としての力にもつながりにくいのが現実です。
本ガイドは、国際的な学習科学の知見（メタ認知・自己調整学習・SOLO Taxonomy・ハッティの効果量研究）を統合し、 松川中学校の日常授業で、どの教科でも使える「振り返りの5段階フレーム」として整理したものです。 職員会議・教科会・学年会でそのまま共通言語として使えるよう設計しました。

1. 理論的基盤：なぜ「振り返り」がそれほど重要なのか

4つの理論の統合： 本ガイドは以下の4つの理論を統合して設計されています。どの教科・どの学年でも、この4本柱は同じです。
理論 提唱者／中核概念 授業での意味
メタ認知理論 フラベル（Flavell, 1979）
「認知についての認知」		 自分が何を分かっていて、何が分かっていないかを 自分で見張る力。中学期は前頭前野の発達期で、この力を伸ばす絶好期。
自己調整学習 ジマーマン（Zimmerman）
3段階モデル：予見→遂行→自己省察		 学習を「計画する→やりながら見張る→振り返って次に生かす」の循環として捉える。高校進学・受験に向けて最も必要な力。
SOLO Taxonomy ビッグス（Biggs）
記述の構造的発達5段階		 振り返り記述が 単一事実 → 関連 → 構造 → 拡張抽象 へと深まるプロセスを可視化。評価規準として使える。
効果量研究 ハッティ（Hattie）
EEFメタ認知ガイダンス		 メタ認知指導の効果量 d ≈ 0.69（7ヶ月分の学習前進に相当）。投資対効果が最も高い指導の一つ。

2. 振り返り「5段階レベル」— 生徒の成長の見取り図

振り返りには「深さの階層」があります。最初からL5を目指す必要はありません。 今どこにいるかを見取り、1段ずつ上げていくことが大事です。 以下の典型記述例は、中学生（1〜3年）が実際に書く言葉を想定しています。

L1 感想レベル　📝 SOLO: 前構造的 / 効果量 ≈ 0

活動の記述と表面的な感想にとどまる段階。まず書けたこと自体を認めるのがスタートライン。中1の4月にはこの段階の生徒が多い。

典型記述： 今日は〇〇をやった ふつうだった むずかしかった めんどくさかった

L2 事実記述レベル　📋 学びの自覚 / SOLO: 単一構造的 / 効果量 ≈ 0.15

何を学んだかを具体的な事実として書ける段階。学びの自覚の芽生え。授業用語・単元の概念が記述に登場する。

典型記述： 連立方程式は2つの文字を消去すれば1元の方程式になると分かった 光合成には光・水・二酸化炭素が必要だと理解した

L3 関連づけレベル　🔗 意味づけ・協働 / SOLO: 多構造的 / 効果量 ≈ 0.40

複数の事実を因果や他者の視点でつなぐ段階。「なぜなら」「〜と似ている」「〇〇さんの考え」が登場する。

典型記述： 加減法より代入法が速かったのは、片方がy=の形だったから。形を見て方法を選ぶと効率がいい 佐藤さんの意見で、自分が見落としていた条件に気づいた

L4 メタ認知レベル　🧠 自己分析・方略選択 / SOLO: 関連構造的 / 効果量 ≈ 0.69

「自分はどう学んだか」「なぜその方法がうまくいったか」を客観的に評価できる段階。学び方自体が分析対象になる。中学期に特に伸ばしたいレベル。

典型記述： 最初に全体を図でまとめてから問題を解くと、式の意味がずれなくなった。自分は「全体像をつかんでから細部」という順序が合っている 分からない時にすぐ答えを見ず、3分考えてから教科書に戻ったら記憶に残った。次のテスト勉強にも使える

L5 転移・価値化レベル　🌟 粘り強さ・回復力・将来接続 / SOLO: 拡張抽象的 / 効果量 ≈ 0.75+

学びを他教科・生活・進路・社会につなげ、自己成長の物語として語れる段階。価値化ができる生徒は学年に数名からスタートし、年間で増やしていく。

典型記述： 「比べるときは基準をそろえる」という考え方は、数学の割合でも、理科の濃度でも、社会の人口密度でも同じ。教科を貫く見方があると気づいた 前回のテスト前より、分からない所を自分で見つけて質問できるようになった。失敗を次に生かせる自分に変わってきている

3. 振り返りを「深める」7つの観点（見取りチェックリスト）

教師が生徒の振り返り記述を見取る際の共通チェックリストです。 合計21点を目安にレベル判定も可能で、観点別学習状況の評価（主体的に学習に取り組む態度）の根拠資料としても活用できます。

# 観点 0点（未記入） 1点（萌芽） 2点（到達） 3点（深化）
1 具体性 白紙・1語 抽象的感想 具体的事実 エピソード＋数値
2 因果・論理 なし 弱い接続 「なぜなら」明確 複数因果を構造化
3 他者への言及 なし 名前のみ 行動・発言を引用 相互作用から気づき
4 自分の学び方 なし 「難しかった」 学習方略を具体記述 方略の有効性を分析
5 次の行動 なし 漠然とした意欲 具体的な行動計画 根拠＋計画＋接続
6 教科横断・既習 なし 曖昧な関連 他教科・既習と明確 複数関連＋比較
7 社会・生活・成長 なし 漠然とした接続 生活と具体接続 価値化＋成長認識

合計点→レベル変換： 0〜3=L1｜4〜7=L2｜8〜11=L3｜12〜16=L4｜17〜21=L5

実用ポイント： 教師は毎回7観点すべてを見る必要はありません。 単元初期は 1・2（具体性・因果）、中盤は 3・4（他者・学び方）、 終末は 5・6・7（次行動・横断・価値化） と、焦点を絞ると指導がぶれません。

4. 日常授業で使える「振り返りの型」— 5つの問いフレーム

振り返りは以下の5つの問いで構成すると、そのまま7観点をカバーできます。 50分授業の時間配分に応じて「3問バージョン」「5問フルバージョン」を使い分けます。 ノート・振り返りシート・Google フォームなど、記述形式は問いません。

短縮3問版（毎時間・終末5分）

  1. ① 今日わかったこと（→観点1・2）
  2. ② どうやって学んだか（→観点4）
  3. ③ 次にいかすこと（→観点5）

L3レベルまで十分届きます。通常授業の標準型として。

フル5問版（単元末・定期テスト前後・10分）

  1. ① 今日わかったこと（観点1・2）
  2. ② どうやって学んだか（観点4）
  3. ③ 次にいかすこと（観点5）
  4. ④ 友だち・教師との学び（観点3）
  5. ⑤ 手ごたえ・これまでの学習とのつながり（観点6・7）

L4〜L5を狙う際の型。単元末・テスト返却時に。

4-1. 書く時間がない日の「口頭 30 秒振り返り」

ペアで30秒ずつ： 「今日 一番大事だった学び は？ それを どうやって 手に入れた？」 → 書かずとも、この2問で L3 のエッセンスに届きます。帰りの会・朝の会でも実施可能。

4-2. 書く時間を「1行だけ」にする日の工夫

1行振り返り： 「〇〇だから△△」の形でノート右下に1行書く。 接続詞「だから／なぜなら／〜と似ている／〜とちがって」のどれかを必ず使う。 この接続詞の強制が L2→L3 への飛躍を促します。

5. 単元を貫く「3層の振り返り」— 入れ子構造で定着させる

層 頻度 狙うレベル 中心の問い
ミクロ
（授業内）		 1時間に1回
終末5分		 L1→L2→L3 今日わかったこと／どうやって学んだか／次にいかすこと
メゾ
（週・単元中盤）		 週1回／単元中盤 L3→L4 この1週間の学び方で一番うまくいったのは？ それはなぜ？
マクロ
（単元末・定期テスト後）		 単元末・定期考査後 L4→L5 この学びは他教科・生活・進路にどうつながる？ 自分はどう変わった？
成長の原則： L1 の生徒にいきなり L5 の問いをすると固まります。ミクロで L2→L3 を安定させてからメゾで L4 を、マクロで L5 を引き出す。 学期を通じて入れ子で積み上げるのが最も効果的です。

6. レベル別・効果的な教師の声かけ（発問テンプレート）

原則： 今のレベルを 否定せず肯定してから、次レベルに必要な「問い」を一つだけ渡す。 中学生は発達的に「指示されること」に抵抗を示しがちなので、「〜しなさい」ではなく「〜はどう？」の問いで終わる形が効果的です。

L1→L2感想から事実記述へ

✓ まず認める

「書けたね、それが第一歩。」
「自分の気持ちを言葉にできていること、大事だよ。」

→ 次の1問

「その『むずかしい』って、具体的にどの場面？」
「今日の授業で一つだけ覚えて帰れるなら何を選ぶ？」

L2→L3事実から関連づけへ

✓ まず認める

「何を学んだかちゃんと書けているね。」
「用語を正確に使えている。」

→ 次の1問

「なぜそうなる？ 『なぜなら』で続けてみて。」
「前に習った〇〇と似ている点はある？」
「友だちの発言で『なるほど』と思ったことは？」

L3→L4関連づけからメタ認知へ

✓ まず認める

「関連づけて考えられているね、深い学びだよ。」
「『だから』『なぜなら』が使えている。」

→ 次の1問

「自分はどうやってその答えにたどり着いた？」
「その学び方は、自分に合っていた？ 次の単元でも使える？」
「うまくいった理由は何だと思う？」

L4→L5メタ認知から転移・価値化へ

✓ まず認める

「自分の学び方を客観的に見られているね、これがメタ認知。」
「学び方そのものを振り返れるのは大人の学習者の力。」

→ 次の1問

「この考え方は、他の教科のどこで使えそう？」
「将来の仕事や生活のどんな場面で役立つ？」
「中1の自分と比べて、何が変わった？」

L5転移・価値化レベルの生徒への声かけ（維持＋広げる）

「研究者のような振り返りだね。ぜひ友だちに『学び方そのもの』を教えてあげて。教えることでさらに深まる。」

→ 学級・学年で「振り返りモデル」として紹介し、他の生徒の手本になってもらう。教えることは最強の学び（プロテジェ効果）。

6-1. 避けたい声かけ（NG集）

NG（振り返りを止める声かけ） なぜNGか
「もっとちゃんと書きなさい」何をどう改善するか示されず、生徒は萎縮する。観点の具体指示が必要。
「感想じゃなくて学びを書いて」感想自体を否定すると書くこと自体への抵抗が生まれる。「感想＋もう一つ」と足し算で。
「友だちのまねはダメ」L3（他者への言及）は成長の証。真似ではなく「〇〇さんから気づいたこと」としてむしろ推奨。
「短いからダメ」量より質。1行でも「なぜなら」が入っていれば L3。長短で評価しない。
「わかりませんと書くな」「わからない」を自覚することこそメタ認知の入口。「どこで」「何が」わからないかに焦点化させる。
「成績に響くよ」と脅す外発的動機に誘導すると記述は表面的になる。「学び方がうまくなる」という内発の言葉で。

7. 教科性を生かした振り返りの焦点化（中学校版）

振り返りの枠は共通でも、教科ごとに焦点を置く観点を変えると「教科の本質に迫るメタ認知」が育ちます。 以下は中学校の教科ごとの推奨焦点と、L3→L4 を狙う発問例です。

国語

焦点観点：2（因果・論理）・3（他者）・7（価値化）

教科性：「ことばで意味を構成する」教科 → 自分の解釈がどう変わったかを言語化

発問例：

  • ・「初読と再読で、どこで読みが変わった？ 根拠は本文のどこ？」
  • ・「〇〇さんの解釈と比べて、自分の読みの強み・弱みは何？」
  • ・「この作品の主題は、今の自分のどんな経験と重なる？」

数学

焦点観点：2（因果・論理）・4（方略）・6（教科横断）

教科性：「構造と一般化」の教科 → 解き方ではなく 「なぜその方法を選んだか」を問う

発問例：

  • ・「なぜ図（式／表／グラフ）を選んだ？ 他の方法とどちらが速い？」
  • ・「小学校で学んだ〇〇の考え方とどうつながる？」
  • ・「この解き方が有効なのはどんな条件のとき？ 別の条件では？」

理科

焦点観点：1（具体性）・2（因果）・6（既習接続）

教科性：「予想 → 検証 → 修正」の教科 → 予想と結果のズレを必ず振り返る

発問例：

  • ・「最初の予想と実験結果、どこがちがった？ なぜ？」
  • ・「この結果から新たに生まれた疑問は？ 次の単元の何につながる？」
  • ・「日常のどんな現象にもこの法則が効いている？」

社会

焦点観点：3（多視点）・6（横断）・7（価値化）

教科性：「多面的・多角的」の教科 → 複数の立場から見直す

発問例：

  • ・「〇〇の立場から見ると、この出来事はどう見える？」
  • ・「今の松川村・日本・世界にどうつながっている？」
  • ・「もし自分が当時の人だったら、どの選択をした？ 根拠は？」

9. 学校全体で取り組むために

最終目標

目指すのは、生徒が卒業までに「自分の頭の中で 5段階・7観点の振り返りを回せる」状態になることです。 そのためには、教科ごとに声かけが違う状態ではなく、学校全体で共通の言葉・共通のレベル観を持つことが欠かせません。 「L3までいけたね」「『なぜなら』が入ると L3 だよ」という共通言語が職員室・教室・家庭の会話に広がれば、 振り返りは学校文化として定着します。

─ これが「自ら学ぶ力」の中核、メタ認知育成のゴールイメージです。

教科会・職員会議で使うための3ステップ

  1. ① 共通理解：本ガイドのP1〜P2を教科会で15分読み合わせ。L1〜L5のイメージを統一する。
  2. ② 試行：1〜2週間、各教科で3問短縮版を実施。回収した記述を教科会で L1〜L5 で判定してみる。
  3. ③ 共有：判定がブレた記述を題材に議論。判定のズレ自体が教師の学びになる。
