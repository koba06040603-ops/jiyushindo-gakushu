## 🔬 ATI交互作用の測定例

### 認知能力 × 構造化レベル の交互作用

```
学習効果
  │
  │     ╱ 高能力学習者（低構造化で最大効果）
  │    ╱
  │   ╱
  │  ╱
  │ ╱
  │╱
  │╲
  │ ╲
  │  ╲  低能力学習者（高構造化で最大効果）
  │   ╲
  │    ╲
  └─────────────────────→ 構造化レベル
    低            高

典型的な適性処遇交互作用（ATI）のパターン
```

### 不安レベル × 評価プレッシャー の交互作用

```
学習効果
  │
  │     ╲ 低不安学習者（高プレッシャーでも維持）
  │      ╲
  │       ╲
  │        ╲
  │         ╲
  │          ╲
  │           ╲ 高不安学習者（高プレッシャーで低下）
  │            ╲
  │             ╲
  │              ╲
  └─────────────────────→ 評価プレッシャー
    低            高

不安レベルによる評価感受性の違い
```
