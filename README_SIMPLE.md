## ✨ システムの特徴

### 🎯 3つのコース制で個別最適化
- **じっくりコース**（基礎）：丁寧にゆっくり学ぶ
- **しっかりコース**（標準）：バランスよく学ぶ
- **ぐんぐんコース**（発展）：挑戦的な問題で学ぶ

### 🤝 4つの助けシステム
1. 💡 **ヒントカード**：3段階のヒント
2. 🤖 **AI先生**：対話で導く温かいサポート
3. 👨‍🏫 **先生を呼ぶ**：すぐに駆けつけます
4. 👥 **友達に聞く**：助け合い学習

### 📊 教師用進捗ボード
- **リアルタイム可視化**：誰がどこまで進んでいるか一目瞭然
- **ヘルプ要請検知**：助けが必要な児童をすぐ発見
- **優先度スコア**：介入が必要な児童を自動判定
- **個人レポート**：AI誤答分析で一人ひとりの課題を把握

### 🎨 ユニバーサルデザイン
- **音声読み上げ**：テキストを音声で再生
- **視覚支援**：ハイライト・フォーカスモード・色分け
- **紙学習対応**：デジタルが苦手な子も安心

## 👨‍🏫 生徒への説明ポイント

### 🎯 授業の最初に伝えること（5分）

#### 【1. 自由進度学習とは？】
```
先生：「今日から新しい学び方を始めます。
      みんなは自分のペースで勉強できます。
      早く進んでもいいし、ゆっくり考えてもいいです。」

子ども：「自分で決めていいの？」

先生：「そうです！でも、ちゃんと理解することが大事です。
      わからないときは、いつでも助けを求めてね。」
```

#### 【2. 3つのコースの選び方】
```
先生：「コースは3つあります。

【じっくりコース】🟢
→ 基本からゆっくり学びたい人
→ 例：「2×3=6」から始めます

【しっかりコース】🔵
→ バランスよく学びたい人
→ 例：「23×4」を学びます

【ぐんぐんコース】🟣
→ 難しい問題に挑戦したい人
→ 例：「237×48」を学びます

どれを選んでも大丈夫！
途中で変えることもできます。」
```

#### 【3. 助けの求め方】
```
先生：「困ったときは、右上の『助けを求める』ボタンを押してね。
      4つの方法があります：

💡 ヒントカード
  → まずはこれ！3つのヒントが見られます

🤖 AI先生に聞く
  → 優しく教えてくれます
  → 答えは教えないけど、考え方を教えてくれます

👨‍🏫 先生を呼ぶ
  → 困ったらいつでも呼んでね
  → すぐに駆けつけます

👥 友達に聞く
  → クラスの中で、この問題ができる友達が見つかります
  → 助け合いましょう」
```

#### 【4. 分かった度の評価】
```
先生：「問題が終わったら、どれくらいわかったか教えてね。

😢 わからない → もう一度やってみよう
😕 少し難しい → ヒントを見てみよう
😊 だいたいOK → いい調子！
😄 よくわかる → すごい！
🤩 完璧！ → 次に進もう

正直に選んでね。わからないのは悪いことじゃないよ。
わからないことがわかるのは、成長の第一歩です！」
```
