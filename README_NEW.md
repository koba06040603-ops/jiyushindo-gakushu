## 🎯 プロジェクト概要

### ビジョン
**すべての子どもたちが、自分らしく学べる環境を作る。**

従来の一斉授業では、理解の早い子は退屈し、ゆっくり学びたい子は置いていかれます。
このシステムは、**一人ひとりの学習ペース**に合わせて、最適な学びを提供します。

### 3つの特徴

#### 1. 📚 3コース制による個別最適化
- **じっくりコース**: 基礎をしっかり理解したい子向け
- **しっかりコース**: 標準的なペースで学びたい子向け
- **ぐんぐんコース**: 発展的な内容に挑戦したい子向け

#### 2. 🤖 AI先生による個別サポート
- 24時間いつでも質問できる
- 段階的ヒント（3段階）で自分で考える力を育てる
- 誤答パターンを分析して、個別アドバイスを提供

#### 3. 👥 協働学習と助け合い
- クラスメートの進捗を確認できる
- 困っている友達を助けられる
- 教え合うことで理解が深まる

## ✨ 主な機能

### 📊 教師向け機能

#### 1. **進捗ボード（リアルタイム）**
- クラス全員の学習状況を一目で把握
- 誰がつまずいているか、優先的にサポートすべき児童を自動判定
- 学習カード・チェックテスト・選択問題の進捗を視覚化

**表示項目:**
- 学習カード進捗（6枚）: 色分けで進捗状況を表示
- チェックテスト進捗（5問）: 正解・誤答を一目で確認
- 選択問題進捗（5題）: 応用力の確認
- ヘルプ要請: 🆘 助けを求めている児童をすぐに発見

#### 2. **個人レポート（AI誤答分析）**
- 各児童の誤答パターンを自動分析
- つまずきの原因を特定（例: くり上がり忘れ、位のずれ、立式ミス）
- AI指導アドバイス: 効果的な指導方法を提案
- 正答率の推移グラフ: 学習の成長を可視化

**使い方:**
1. 進捗ボードで「AI誤答分析で詳しく見る」をクリック
2. 分析したい児童を選択
3. 詳細レポートを確認

#### 3. **週次・月次レポート**
- 1週間・1ヶ月の学習状況をPDFで出力
- 保護者面談や学級通信に活用

#### 4. **AI単元生成**
- 教科書会社・学年・単元を選択
- AIが学習カード・チェックテスト・選択問題を自動生成
- 先生の教材準備時間を大幅削減

### 🎓 児童・生徒向け機能

#### 1. **学習カード（6枚）**
- 新出語句・キーワードの説明
- 例題と解き方
- 練習問題（最小レベル・標準レベル・上級レベル）
- 実社会との関連付け

#### 2. **3段階ヒント機能**
- ヒント1: 考え方のヒント
- ヒント2: 具体的な手順
- ヒント3: 詳しい解説

#### 3. **AI先生に質問**
- わからないことをいつでも質問
- 段階的にヒントをもらえる
- 自分で考える力を育てる

#### 4. **チェックテスト（5問）**
- 学習カード6枚を完了した後に挑戦
- 理解度を確認

#### 5. **選択問題（5題）**
- チェックテスト5問を完了した後に挑戦
- 応用力を試す発展的な問題

#### 6. **友達助け合い機能**
- クラスメートの進捗を確認
- 困っている友達を見つけて助けられる
- 「助けて」ボタンでヘルプ要請

### 🎨 ユニバーサルデザイン機能

#### 1. **テキスト読み上げ（音声サポート）**
- 問題文・解説を音声で聞ける
- 速度調整可能
- 読むのが苦手な子をサポート

#### 2. **動的視覚支援**
- 数式の色分け表示: 演算子や数字を色で区別
- テキストサイズ調整: 見やすい大きさに変更
- ハイコントラストモード: 視認性向上
- フォーカスモード: 周りを暗くして集中

#### 3. **ステップバイステップ表示**
- 解き方を段階的に表示
- アニメーション付きで理解しやすい

## 📚 使い方（児童・生徒向け）

### はじめ方

#### 1. ログイン
- 先生からもらったメールアドレスとパスワードでログイン
- 例: student1@school.jp / 123

#### 2. 単元を選ぶ
- 学年・教科・単元を選択
- 例: 小学3年生 → 算数 → かけ算の筆算

#### 3. コースを選ぶ
**3つのコースから自分に合ったものを選びましょう:**

##### 🐢 じっくりコース
- **こんな人におすすめ**: ゆっくり、しっかり理解したい
- **特徴**: 基礎問題が多い、くり返し練習できる
- **目標**: 基本をしっかりマスター

##### 🚶 しっかりコース
- **こんな人におすすめ**: 標準的なペースで学びたい
- **特徴**: バランスの取れた問題、応用問題も少しある
- **目標**: 教科書レベルをクリア

##### 🚀 ぐんぐんコース
- **こんな人におすすめ**: どんどん先に進みたい、難しい問題に挑戦したい
- **特徴**: 発展問題が多い、考える問題が中心
- **目標**: 応用力を身につける

**💡 ポイント**: コースは途中で変更できます。自分のペースで学びましょう！

#### 4. 学習カードに取り組む

**学習カードは6枚あります:**

##### 📖 カードの構成
1. **新出語句・キーワード**: 新しく出てくる言葉の説明
2. **例題と解き方**: 先生と一緒に解く問題
3. **練習問題**: 自分で解く問題（最小・標準・上級の3レベル）
4. **実社会との関連**: 実生活でどう使うか

##### 💡 困ったときは...

**1. 3段階ヒント機能**
- **ヒント1**: 考え方のヒント → まず自分で考えてみよう
- **ヒント2**: 具体的な手順 → もう少しヒントがほしいとき
- **ヒント3**: 詳しい解説 → それでもわからないとき

**2. AI先生に質問**
- 「どうしてこうなるの？」
- 「もっと簡単な説明がほしい」
- なんでも聞いてOK！

**3. 友達に助けを求める**
- 「助けて」ボタンを押すと、クラスメートに通知
- 助けられる友達が来てくれる

#### 5. チェックテストに挑戦

**学習カード6枚を全部完了したら、チェックテストに進めます。**

- 問題数: 5問
- 目的: 理解度を確認
- 合格: 3問以上正解

#### 6. 選択問題に挑戦

**チェックテスト5問を全部完了したら、選択問題に進めます。**

- 問題数: 5題
- 目的: 応用力を試す
- 特徴: 考えさせる問題、発展的な内容

## 📄 紙学習への対応

**デジタルが苦手な子や、家にタブレットがない子も安心！**

紙でも同じように学べる工夫をしています。

### 対応策

#### 1. 個人レポート → 紙版
- **誤答記録シート**: 手書きで誤答を記録
- **成長グラフシート**: 自分でグラフを描く
- **先生からのアドバイスカード**: 指導ポイントを記載

#### 2. 音声読み上げ → 紙版
- **QRコード付き音声ガイド**: スマホで読み上げ音声を再生
- **ルビ（ふりがな）版プリント**: 漢字にふりがな
- **音声ペン対応**: 市販の音声ペン（G-Talk等）でタッチ再生

#### 3. 視覚支援 → 紙版
- **色分けプリント**: 数式を色分けで視覚化
- **拡大プリント**: 1.5倍・2倍サイズ
- **フォーカスシート**: 透明シートで読みたい部分だけ表示
- **ステップバイステップシート**: めくり式で段階的に表示

#### 4. リアルタイム通信 → 紙版
- **ヘルプカード**: 机に立てて助けを求める
- **進捗ボード（教室掲示）**: 全員の進捗を共有
- **色付きクリップ**: 赤=ヘルプ、黄=確認、緑=順調

### ハイブリッド運用

**デジタル・紙・ハイブリッドを選択できます:**

- **フルデジタル**: タブレットで学習
- **フル紙**: プリントで学習
- **ハイブリッド**: 学校はデジタル、家は紙

**週1回のサイクル例:**
```
月〜木: 紙で学習
  ↓
金曜日: 誤答記録をデジタル入力
  ↓
AI分析実行
  ↓
個人レポート印刷・配布
  ↓
週末: 家庭で振り返り（紙）
```

**詳細**: [紙学習対応ガイド](./PAPER_LEARNING_SUPPORT.md)

## 🛠️ 技術スタック

### フロントエンド
- **Hono**: 軽量Webフレームワーク
- **TypeScript**: 型安全な開発
- **Tailwind CSS**: ユーティリティファーストCSS
- **Axios**: HTTPクライアント
- **Chart.js**: グラフ描画

### バックエンド
- **Cloudflare Workers**: エッジコンピューティング
- **Cloudflare D1**: SQLiteベースのグローバル分散DB
- **Wrangler**: Cloudflare開発ツール

### AI・機械学習
- **Google Gemini API**: AI対話・分析
- **TensorFlow.js**: ブラウザ内機械学習

### その他
- **Web Speech API**: テキスト読み上げ
- **html2pdf.js**: PDF生成
- **QRCode.js**: QRコード生成

## 🚀 開発者向け情報

### ローカル開発環境のセットアップ

```bash
# リポジトリのクローン
git clone https://github.com/ユーザー名/jiyushindo-gakushu.git
cd jiyushindo-gakushu

# 依存関係のインストール
npm install

# ローカル開発サーバーの起動
npm run dev

# ブラウザで開く
open http://localhost:3000
```

### ビルド・デプロイ

```bash
# ビルド
npm run build

# Cloudflare Pagesにデプロイ
npm run deploy
```

### データベースマイグレーション

```bash
# ローカルDBのマイグレーション
npm run db:migrate:local

# 本番DBのマイグレーション
npm run db:migrate:prod

# データベースのシード
npm run db:seed
```

### プロジェクト構造

```
jiyushindo-gakushu/
├── src/
│   └── index.tsx           # メインアプリケーション
├── public/
│   └── static/
│       ├── app.js          # フロントエンドロジック
│       ├── tts.js          # テキスト読み上げ
│       ├── visual-support.js   # 視覚支援
│       └── realtime.js     # リアルタイム通信
├── migrations/             # データベースマイグレーション
├── wrangler.jsonc          # Cloudflare設定
├── package.json
└── README.md
```
