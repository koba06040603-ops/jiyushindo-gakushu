##### **A1: 理論1（資質・能力） ⇄ 理論2（自己調整）**

```
【双方向の強い相互作用】

資質・能力 ─────↗↗────→ 自己調整
     ↑                      │
     └──────────↗───────────┘

【方向1】資質・能力 → 自己調整（強）

思考力が高い → メタ認知が発達 → 自己調整能力向上

実証研究:
- Schunk & Zimmerman (2008): 学業成績と自己調整の相関 r=0.64
- 因果: 思考力 → 自己評価の正確性 → 適切な目標設定

発達段階での現れ:
├─ 小1-2: 知識の獲得 → 簡単な振り返り
├─ 小3-4: 思考力の芽生え → 計画立案の開始
├─ 小5-6: 思考力の深化 → 自己調整の自動化
└─ 中1-3: 抽象的思考 → 長期的な自己調整

【方向2】自己調整 → 資質・能力（強）

自己調整能力が高い → 効果的な学習 → 資質・能力の向上

実証研究:
- Dignath & Büttner (2008): 自己調整訓練 → 学業成績向上 d=0.69
- メカニズム: 計画→実行→評価のサイクルが知識を定着

発達段階での現れ:
├─ 小1-2: 教師の指示に従う → 基礎的知識獲得
├─ 小3-4: 自分で計画 → 知識の体系化
├─ 小5-6: 方略の選択 → 思考力の向上
└─ 中1-3: 高度な自己調整 → 深い理解と応用力
```

**実践での活用**:
```
【介入設計】
低資質・低自己調整 → 構造化された支援
高資質・低自己調整 → 自己調整訓練
低資質・高自己調整 → 基礎知識の補充
高資質・高自己調整 → 発展課題
```

##### **A2: 理論1（資質・能力） ⇄ 理論3（見方・考え方）**

```
【双方向の強い相互作用】

【方向1】資質・能力 → 見方・考え方（強）

知識・技能の蓄積 → 教科的スキーマの形成 → 見方・考え方の発達

実証研究:
- Chi et al. (1981): 専門知識 → 深い概念的理解
- 物理の専門家: 表層的特徴でなく、原理で問題を分類

メカニズム:
┌─────────────────────────────────────┐
│ 段階1: 断片的知識（個別の事実）    │
│        ↓                            │
│ 段階2: 知識の関連付け              │
│        ↓                            │
│ 段階3: スキーマの形成（見方）      │
│        ↓                            │
│ 段階4: 自動的な適用（考え方）      │
└─────────────────────────────────────┘

教科別の例:
【算数】
├─ 知識: 個別の計算手順
├─ 関連付け: 四則演算の関係
├─ 見方: 数量関係に着目
└─ 考え方: 論理的・帰納的推論

【理科】
├─ 知識: 個別の実験結果
├─ 関連付け: 因果関係の発見
├─ 見方: 条件制御の視点
└─ 考え方: 仮説検証的思考

【方向2】見方・考え方 → 資質・能力（強）

教科的思考が発達 → 深い理解 → 思考力・判断力の向上

実証研究:
- Novak (2010): 概念地図の使用 → 深い理解 d=0.62
- メカニズム: 見方・考え方 → 転移可能な思考力

発達段階での現れ:
小1-2: 具体的な見方 → 観察力
小3-4: 関係的な見方 → 比較・分類能力
小5-6: 抽象的な見方 → 推論力
中1-3: 統合的な見方 → 批判的思考
```

**実践での活用**:
```
【診断】
高知識・低見方 → 暗記型学習
低知識・高見方 → 知識不足だが思考力あり
高知識・高見方 → 専門家レベル

【介入】
高知識・低見方 → 概念地図、Why質問
低知識・高見方 → 知識の補充、事例の蓄積
```

##### **A6: 理論1（資質・能力） ⇄ 理論7（認知負荷）**

```
【双方向の相互作用（適正負荷の重要性）】

【方向1】資質・能力 → 認知負荷（負の相関）

知識・技能が高い → 同じ課題の認知負荷が低い

実証研究:
- Sweller (1988): 専門知識 → 認知負荷の減少
- メカニズム: 自動化、チャンク化

具体例:
【算数初心者】
2桁の掛け算: 認知負荷 8/9 (非常に高い)
├─ 桁ごとの計算
├─ 繰り上がり
├─ 位の管理
└─ すべてを同時処理 → WM過負荷

【算数熟達者】
2桁の掛け算: 認知負荷 2/9 (低い)
└─ 自動化された手続き → WM負荷小

【方向2】認知負荷 → 資質・能力（逆U字関係）

適切な認知負荷（ZPD内） → 資質・能力の向上
過負荷 or 過小負荷 → 学習効率低下

実証研究:
- Paas & Van Merriënboer (2020): 
  最適負荷ゾーン（4-6/9）で学習効率最大

┌─────────────────────────────────┐
│ 学習効率                        │
│   │                             │
│ 高│      ╱￣╲                  │
│   │    ╱     ╲                 │
│   │  ╱         ╲               │
│ 低│╱             ╲             │
│   └─────────────────→          │
│     低   中   高   過   認知負荷│
│                                 │
│ 最適ゾーン: 中程度の負荷        │
└─────────────────────────────────┘

実践的意味:
├─ 簡単すぎる → 退屈、成長なし
├─ 適度に難しい → 集中、成長
└─ 難しすぎる → フラストレーション、回避
```

```
  ↓

ZPD内の学習 → 効果的な能力向上

実証研究:
- Vygotsky (1978): 「教育は発達を先導する」
- ZPD内の学習 → 最大の発達効果

メカニズム:
独力では難しい課題
  ↓
適切な支援（足場かけ）
  ↓
成功体験 + 新しいスキーマの獲得
  ↓
資質・能力の向上
```

##### **B4: 理論2（自己調整） → 理論6（社会とのつながり）**

```

  ↓

実証研究:

  ↓

【自己調整低い → 短期的視点】
目標: 「テストで良い点を取りたい」
  ↓
```

## 2. 因果関係モデルの詳細

### 2.1 因果の方向性と強度の定量化

```
【因果関係の強度分類】

弱い影響 (Weak)
├─ 相関係数: r = 0.2-0.3
├─ 因果効果: β = 0.1-0.2
└─ 例: MI適性 → 社会性

中程度の影響 (Moderate)
├─ 相関係数: r = 0.4-0.6
```
