## 1. システム全体像 — 「子どもを12の視座で理解し、理解に基づいて応じる」

### 基本思想
> 「子どもは今この瞬間、学んでいる。12の視座で理解し、理解に基づいて応じる。」

このシステムは、教育心理学・学習科学の12の主要理論を統合し、AIが一人ひとりの子どもの「今の姿」を多角的に理解し、その理解に基づいてリアルタイムに学習環境を最適化する仕組みです。

### システムの流れ（上流から下流へ）

```
教師が単元を入力
     ↓
AI が3コース自動生成（じっくり🐢 / しっかり🐇 / ぐんぐん🚀）
     ↓
児童の学習データをD1データベースから収集
     ↓
★ v4エンジン: 12理論プロファイルを構築
     ↓
★ v4エンジン: 5つの基幹軸を算出
     ↓
★ v4エンジン: 8つのアーキタイプで「今の姿」を判定
     ↓
★ v4エンジン: 統合制御パラメータを算出
     ↓
Gemini AI がパラメータに基づき個別最適化カードを生成
     ↓
児童が学習カードで学ぶ（AI先生・ヒント・採点・振り返り）
     ↓
学習ログが蓄積 → プロファイル更新 → 次の最適化へ（循環）
```

### 12理論の4つのカテゴリ

**【知覚・認知の入口】**（世界をどう受け取るか）
- F1: 感覚チャネル（視覚・聴覚・読字・身体運動）
- F2: 多重知能（言語・論理数学・空間・身体運動・音楽・対人・内省・博物的）＋成長マインドセット
- F3: 経験学習サイクル（具体的経験→省察的観察→抽象的概念化→能動的実験）

**【認知構造・方略】**（どう学ぶか）
- F4: 適性×指導の交互作用（事前知識・認知能力・不安・独立性）
- F6: 認知方略（検索練習・間隔反復・交互配置・精緻化・二重符号化）
- F10: 教科固有の知識構造（初学→習熟→熟達）

**【自己調整・メタ認知】**（自分の学びを舵取りできるか）
- F5: 自己調整学習の3位相（予見→遂行→省察）
- F7: 最近接発達領域と足場かけ（自力で→支援ありで→できる範囲）
- F9: メタ認知（自分の思考を見つめ、制御する力）

**【動機・感情・意味】**（なぜ学ぶか）
- F8: 自己決定理論の3欲求（自律性・有能感・関係性）
- F11: 真正な文脈（学びが「自分のもの」になっているか）
- F12: 達成感情（楽しさ・不安・退屈・フロー状態）

## 3. 12理論 → 5つの基幹軸 — 次元削減

12の理論プロファイル（100以上の変数）を、5つの基幹軸に圧縮する。

### 5つの基幹軸

| 軸 | 名前 | 構成要素 | 意味 |
|----|------|---------|------|
| 軸1 | 認知的自律性 | F5(自己調整)×F4(独立性)×F9(メタ認知) | 自分で学びの舵を取れるか |
| 軸2 | 情緒的安定性 | (100-F4.不安)×F12(感情価値)×F8(有能感) | 安心して学べているか |
| 軸3 | 認知的入口選好 | F1(感覚チャネル)×F2(知能プロファイル) | どのモードで学びに入るか |
| 軸4 | 方略的成熟度 | F6(習得度)×F6(検索練習力)×F6(精緻化) | 効果的な学び方を知っているか |
| 軸5 | 動機的エネルギー | F8(内発的動機)×F11(自分ごと度)×F12(フロー確率) | 学びたい気持ちがあるか |

### 算出式（簡略化）

```
認知的自律性 = SRL発達段階×0.4 + 独立性×0.35 + メタ認知的調整×0.25
情緒的安定性 = (100-不安度)×0.4 + 感情価値×0.3 + 有能感×0.3
方略的成熟度 = 単元習得度×0.5 + 検索練習力×0.3 + 精緻化力×0.2
動機的エネルギー = 動機連続体×0.4 + 個人的関連性×0.3 + フロー確率×0.3
```

## 4. 8つのアーキタイプ — 「今この子がどんなふうに学んでいるか」

> **アーキタイプは分類ではない。「今この子がどんなふうに学んでいるか」の描写である。同じ子が、月曜日にはAで、水曜日にはDであることもある。**

### 8つの姿

| ID | 名前 | 今の姿（子ども中心の描写） | 軸パターン | 出現率 | 応じ方 |
|----|------|-------------------------|-----------|--------|--------|
| A | 自律的探究者 | 知りたいことがあり、自分のやり方で進んでいる。夢中になっている。 | 認知H 情緒H 方略H 動機H | 8% | そばにいる。求められたら応じる。邪魔をしないことが最善。 |
| B | 堅実な努力家 | コツコツと取り組んでいる。着実に前に進んでいる。 | 認知M 情緒H 方略M 動機H | 15% | 見守りながら、少しずつ高い方略への道を拓く。 |
| C | 直感的冒険者 | 直感で動く。型にはまらない。面白いものに飛びつく。 | 認知M 情緒H 方略L 動機M | 10% | 冒険を認めつつ、振り返りの習慣を静かに育てる。 |
| D | 慎重な完璧主義者 | 丁寧に考える力がある。でも「間違えたらどうしよう」が先に来る。 | 認知H 情緒L 方略H 動機L | 12% | 「間違えても大丈夫」を体験で伝える。慎重さは強み。 |

## 8. 自由進度学習の全体フロー — 教師と児童の動き

### 教師の動き

```
1. 学年・教科・単元名を入力（例：小5算数「割合」）
2. AIが約1分で3コース×学習カードを自動生成
   - 🐢 じっくりコース（基礎重視・丁寧な足場）
   - 🐇 しっかりコース（標準・バランス型）
   - 🚀 ぐんぐんコース（発展・探究型）
3. 教師がカードを確認・編集（内容、画像、動画、難易度を修正可能）
4. チェックテスト（6問）＋ えらべるもんだい（6問）を自動生成
5. 個別最適化コースを児童ごとに生成（v4エンジン使用）
6. 児童用ページURLを配信
7. 振り返りデータ・学習ログをダッシュボードで確認
```

### 児童の動き

```
1. 自分のコースを選ぶ（または個別コースを受け取る）
2. 学習カードに順番に取り組む
   - AI先生の励まし → 問題を読む → 考えて答える → 答え合わせ
   - 困ったら: ヒント(3段階) / AI先生に質問 / 読み上げ / 友達に聞く / 先生ヘルプ
3. チェックテスト（6問）に挑戦
4. えらべるもんだい（6問から好きなものを選ぶ）
   - 実生活の問題 / 他教科とのつながり / ゲーム型 / 仕事場面 / 探究型
5. 毎時間の振り返り（わかったこと・学び方・次にいかすこと・友達との学び）
6. AIが振り返りを分析し、次の学習を最適化
```
