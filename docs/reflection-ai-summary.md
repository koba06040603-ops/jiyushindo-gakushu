## 1. 理論基盤（6理論 + 補助理論の統合）

| 理論 | 提唱者 | 効果量 | 学習科学的根拠 | システム実装 |
|------|--------|--------|---------------|-------------|
| **自己調整学習** | Zimmerman | d=0.52 | 予見→遂行→省察のサイクルで自律的学習者を育成 | N問ごとのミニ振り返り (😊🤔😰 3択 → scaffold/interval調整) |
| **メタ認知理論** | Flavell | d=0.69 | 自分の思考を認知・制御する「考えることを考える」能力 | 不正解時の4択自己分析UI (忘れた/読み間違い/計算ミス/わからない) |
| **振り返り5段階** | Hattie | d≥0.75 | 「よかった点→改善点→学んだこと」の質的深化をAIが評価 | POST /api/ai/reflect hourly(150字) / unit(200字) フィードバック |
| **感情ゲート理論** | Pekrun (2006) | ─ | 不安・退屈が学習ゲートを閉じる → AIコーチが感情を再活性化 | 7段階の気分適応パラメータ 声がけトーン・ヒント自動展開を制御 |
| **足場かけ (ZPD)** | Vygotsky | d=0.40 | 最近接発達領域内で適切な支援→漸次撤去 | scaffoldLevel (1.0→0.2) 3連続正解で-0.2、不正解で+0.3復帰 |
| **成長マインドセット** | Dweck (2006) | ─ | 能力固定観→成長観へ 努力・過程を評価する称賛 | 正答率に応じた3段階称賛 努力→プロセス→方略 |

**補助理論**: Kolb経験学習サイクル（CE→RO→AC→AE の4段階表示で学習体験を構造化）

## 3. 返答方法 ─ AIコーチ 5つのトリガー

### T1: カード表示時 (aiCoachOnCardOpen)
- 7気分 × 各2-3フレーズ からランダム選択
- **gentleMode + 難問** → ヒント自動展開 + info吹き出し
- **3連続不正解** → crisis介入（ヒント強制＋先生案内）
- **3連続正解 + excited** → チャレンジ促進

### T2: 考え中の励まし (startThinkingTimer)
- gentle時 **45秒** / 通常 **60秒** 経過で発動
- トーン別メッセージ（gentle/calming/empathic/energetic/positive/neutral）
- 2ページ目以降＆連続2エラー未満 → 50%確率で抑制

### T3: 正解時 (aiCoachOnCorrect)
- 7トーン別の称賛フレーズ [celebrate] 4秒
- **F2 成長マインドセット称賛:**
  - 正答率70%+ & 2連続正解 → **方略称賛**「やり方がよかった」
  - 正答率40%+ → **プロセス称賛**「がんばり方がいい」
  - 正答率40%未満 → **努力称賛**「チャレンジえらい」
- **F8** 5連続→「天才！🏆」、3連続→「その調子！🔥」
- **F7** 3連続正解で scaffoldLevel を -0.2

### T4: 不正解時 (aiCoachOnIncorrect)
- 7トーン別の共感フレーズ [comfort] 6秒
- 2連続不正解 + autoHint → ヒント自動展開
- 3連続不正解 → [crisis] 介入
- **F7** scaffoldLevel < 0.8 なら +0.3 復帰
- **F9** メタ認知プロンプト（4択の自己分析UI）

### T5: ミニ振り返り (F5 / N問ごとに発動)
| 回答 | scaffold変化 | interval変化 |
|------|-------------|-------------|
| 😊 わかってきた | -0.1 | +1 |
| 🤔 まあまあ | 変化なし | 変化なし |
| 😰 むずかしい | +0.2 | -1 |

reflectionInterval: デフォルト5問。好調時→7問に延長、困難時→3問に短縮。

## 4. 振り返りAPI仕様 (POST /api/ai/reflect)

### 入出力仕様

| 項目 | hourly（1時間） | unit（単元全体） |
|------|:---------------:|:---------------:|
| 入力 | { type, reflections: { grade, good, bad, learned } } ||
| 文字数上限 | **150字** | **200字** |
| maxTokens | 200 | 300 |
| temperature | 0.8 | 0.8 |
| モデル | gemini-2.5-flash-lite | gemini-2.5-flash-lite |

### AIプロンプト 5原則
1. 必ず **「がんばったね」「すごいね」** で始める
2. よかったことを **具体的** にほめる
3. **否定語禁止**（ダメ/できていない/不十分）
4. 学年に応じたトーン（中学生→親しみ+敬意 / 小学生→あたたかく）
5. **次への意欲** を引き出す前向きな提案

**フォールバック:** API未設定時は定型メッセージを返却

## 5. 声がけUI ─ 6タイプの吹き出し (showCoachBubble)

| タイプ | 用途 | 背景色 | icon | 使用場面の例 |
|--------|------|--------|------|------------|
| **encourage** | 励まし | 緑系 | 💚 | カード開始時の声がけ、基本選択時の応援 |
| **warn** | 注意喚起 | 黄系 | ⚠️ | 時間超過時の確認、難度注意 |
| **comfort** | 慰め・共感 | ピンク | 💗 | 不正解時の共感メッセージ、疲れ時の声がけ |
| **celebrate** | 祝福・称賛 | 青系 | 🎉 | 正解時の称賛、連続正解のマイクロ成功 |
| **info** | 情報・ヒント | 紫系 | 💬 | 考え中の励まし、gentleMode時の支援 |
| **crisis** | 危機介入 | 赤系 | 🆘 | 3連続不正解、深刻な困難検知時 |

全吹き出しは画面下部固定表示 + TTS自動読み上げ対応。

## 6. セッション動的制御変数 (window._v4Session)

| 変数 | 説明 | 範囲・閾値 |
|------|------|-----------|
| **scaffoldLevel** | 足場レベル | 1.0(フル)→0.2(自力) / ≤0.4でヒント非表示 |
| **scaffoldFadeCount** | 連続正解カウンタ | 閾値3で-0.2フェーディング |
| **reflectionInterval** | ミニ振り返り間隔 | デフォルト5問 (3-7可変) |
| **consecutiveErrors** | 連続不正解数 | 2→autoHint / 3→crisis |
| **consecutiveCorrects** | 連続正解数 | 3→scaffold減 / 5→天才! |
| **kolbPhase** | 経験学習フェーズ | CE→RO→AC→AE循環 |
