## 6. 社会科

### 6.1 社会科の見方・考え方（DCS）

**社会科固有の認知構造**

```
【社会科の見方・考え方】

「社会的な見方・考え方」
= 社会的事象を、位置や空間的な広がり、時期や時間の経過、
  事象や人々の相互関係などに着目して捉え、
  比較・分類、総合、地域の人々や国民の生活と関連付けること

具体的要素:
├─ 地理的な見方（位置、分布、場所、人間と自然環境との相互依存）
├─ 歴史的な見方（推移、比較、相互の関連、現在とのつながり）
├─ 公民的な見方（対立と合意、効率と公正、分業と交換、希少性）
└─ 持続可能性の視点（現在と未来のつながり）
```

**認知科学的基盤**

- **空間認知**: 地図、地形の理解
- **時間認知**: 歴史的時間の把握、因果関係
- **社会的認知**: 他者理解、多様な視点
- **批判的思考**: 資料の信頼性評価、多角的考察
- **市民的リテラシー**: 民主主義、法、権利と義務

**エビデンス**

- Hess, D. E. (2009). *Controversy in the Classroom*. Routledge. → 論争的問題の教育効果
- Seixas, P., & Morton, T. (2013). *The Big Six Historical Thinking Concepts*. Nelson Education. → 歴史的思考力

### 6.2 社会科における8理論の統合マップ

```yaml
【T1: 資質・能力の3つの柱】
  知識・技能:
    - 地理的知識（地形、気候、産業、文化）
    - 歴史的知識（時代、人物、出来事）
    - 公民的知識（政治、経済、国際社会）
    - 資料活用技能（地図、年表、グラフ）
    
  思考・判断・表現:
    - 課題の設定
    - 多角的な考察（複数の立場）
    - 比較、関連付け、総合
    - 判断、構想
    
  学びに向かう力:
    - 社会的事象への関心
    - 主体的な社会参画
    - 持続可能な社会への態度

【T2: 自己調整学習】
  計画:
    - 調査の計画（何を、どう調べるか）
    - 資料の選択
    
  モニタリング:
    - 資料の信頼性チェック
    - 考察の妥当性確認
    
  方略:
    - 複数資料の比較
    - 図表化（地図、年表、グラフ）
    - 異なる視点の検討
    
  振り返り:
    - 学習過程の省察
    - 新たな疑問の発見

【T3: 見方・考え方（DCS）】
  地理的な見方:
    - 位置、分布、場所
    - 人間と自然環境
    
  歴史的な見方:
    - 時期、推移、比較
    - 因果関係、現在とのつながり
    
  公民的な見方:
    - 対立と合意、効率と公正

【T4: MI適性】
  言語的知能:
    - 資料読解、説明・発表
    
  論理数学的知能:
    - データ分析、因果推論
    
  空間的知能:
    - 地図、地形の理解
    
  対人的知能:
    - 多様な視点の理解

【T5: 協働学習】
  グループ調査:
    - 役割分担（資料収集、整理、発表）
    
  ディスカッション:
    - 論争的問題の議論
    - 多様な立場の検討

【T6: 社会とのつながり】
  実社会との関連:
    - 地域社会、現代的課題
    
  社会参画:
    - 社会の一員としての意識

【T7: 認知負荷】
  内在的負荷:
    - 資料の難易度
    
  外在的負荷:
    - 資料の量、提示方法
    
  本有的負荷:
    - 歴史的・地理的スキーマ形成

【T8: ZPD】
  現在の発達水準:
    - 独力で読解できる資料
    
  最近接領域:
    - 支援があれば理解できる資料
    
  足場かけ:
    - 資料読解の観点、時代背景の説明
```

### 6.3 発達段階別設計

#### 【段階1】小学校1-2年（6-8歳）：生活科

**発達的特徴**

- **地域認識**: 身近な場所、人々
- **時間認識**: 「昔」の概念（おじいさん、おばあさんの子ども時代）
- **社会認識**: 家族、友達、学校

**8理論の重点（生活科として）**

| 理論 | 重点内容 |
|------|----------|
| T1 | 身近な地域、人々への気づき |
| T2 | 「調べてみよう」の意識 |
| T3 | 「場所」「人とのつながり」への気づき |
| T4 | 直接体験、インタビュー |
| T5 | ペアで調べる、発表し合う |
| T6 | 身近な社会（家庭、学校、地域） |
| T7 | 具体的体験、視覚的支援 |
| T8 | 少し遠い場所への探検 |

**学習活動例**

```
【単元例】「まちたんけん」（小2・8時間）

時1-2: 一人学び「行きたい場所を考える」
  - 地域の地図を見る
  - 行きたい場所を選ぶ
  - 【学習カード32】たんけん計画
    行きたい場所: [   ]
    知りたいこと: [   ]

時3-4: 協働「グループで探検」
  - グループで地域探検
  - 見つけたこと、聞いたことを記録
  - 【診断ポイント】観察、インタビュー、協働

時5-6: 一人学び「まとめる」
  - 絵と文でまとめる
  - 【学習カード33】たんけんカード
    場所: [   ]
    見つけたこと: [   ]
    絵: [   ]

時7: 協働「発表」
  - グループで発表
  - 【診断ポイント】表現、協働

時8: 振り返り
  - 楽しかったこと、もっと知りたいこと
```

## 7. 英語科（外国語）

### 7.1 英語科の見方・考え方（DCS）

**英語科固有の認知構造**

```
【外国語の見方・考え方】

「外国語によるコミュニケーションにおける見方・考え方」
= 外国語で表現し伝え合うため、外国語やその背景にある文化を、
  社会や世界、他者との関わりに着目して捉え、
  コミュニケーションを行う目的や場面、状況等に応じて、
  情報や自分の考えなどを形成、整理、再構築すること

具体的要素:
├─ 音声・音韻（発音、イントネーション、リズム）
├─ 語彙・語法（語の意味、コロケーション）
├─ 文法・統語（文構造、語順）
├─ 談話・語用（場面、相手、目的に応じた表現）
└─ 文化理解（異文化への気づき、多様性の尊重）
```

**認知科学的基盤**

- **音韻認識**: 英語特有の音素の認識
- **語彙習得**: 形態・意味・統語情報の統合
- **文法処理**: 語順、時制などの処理
- **語用能力**: 場面・相手に応じた適切な表現
- **異文化理解**: 文化的文脈の理解
- **コミュニケーション方略**: 推測、言い換え、確認

**エビデンス**

- Ellis, R. (2015). *Understanding Second Language Acquisition* (2nd ed.). Oxford University Press. → 第二言語習得理論
- Swain, M. (1985). Communicative competence. *Applied Linguistics*, 6(2), 96-112. → アウトプット仮説

```
  - 学習の振り返り
```

**ルーブリック（中1-3: 英語）**

| 観点 | ⭐️⭐️⭐️⭐️ (4) | ⭐️⭐️⭐️ (3) | ⭐️⭐️ (2) | ⭐️ (1) |
|------|---------------|-------------|----------|---------|
| **聞くこと** | 自然な速度の英語を理解、推測活用 | ゆっくり明瞭な英語を理解 | 繰り返しで理解 | 理解が困難 |
| **読むこと** | まとまりのある文章を理解、推測活用 | 簡単な文章を理解 | 単文を理解 | 理解が困難 |
| **話すこと** | 即興的に意見を述べる、やり取り継続 | 準備した内容を話す | 簡単な文で話す | 発話が困難 |
| **書くこと** | まとまりのある文章を論理的に書く | 簡単な文章を書く | 単文を書く | 書くことが困難 |
| **自己調整（T2）** | 方略を自覚的に選択・評価、メタ認知 | 方略を意識的に使用 | 教師の促しで方略使用 | 方略使用が限定的 |
| **協働（T5）** | ディスカッションをリード、建設的フィードバック | 議論に積極参加 | グループ活動に参加 | 協働に消極的 |

### 7.6 AI診断プロンプト（英語科）

```yaml
英語科AI診断プロンプト（Gemini用）

システム指示:
  あなたは小学校・中学校の英語教育（外国語教育）の専門家です。
  児童生徒の学習カードを分析し、8理論に基づいて診断的フィードバックを生成してください。

  - 学年: [小3/小4/.../中3]
  - 学習カードの内容: [JSON形式]
  - 発達段階の情報: [段階2-4]
  - 技能: [聞く/読む/話す/書く]

  1. T1: 資質・能力
     - 知識・技能（音声、語彙、文法）
     - 思考・判断・表現（聞く、読む、話す、書く）
     - 学びに向かう力（コミュニケーション意欲、異文化理解）
  
  2. T2: 自己調整学習
     - 計画（表現の計画）
     - モニタリング（理解度、表現の適切性）
     - 方略使用（推測、言い換え、確認）
     - 振り返り（コミュニケーションの省察）
  
  3. T3: 見方・考え方（DCS）

  7. T7: 認知負荷

     - カード名: [   ]
     - 理由: [   ]
     - 重点: [   ]

  - 肯定的、コミュニケーションを励ます

  - 異文化理解を促す
```
