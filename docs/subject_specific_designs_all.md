## 1. 11教科統合設計の全体像

### 1.1 設計の構造

```
【統合設計の4次元構造】

次元1: 8理論の統合
├─ T1: 資質・能力（3つの柱）

├─ T7: 認知負荷理論
└─ T8: ZPD

次元2: 発達段階
├─ 段階1: 小1-2（6-8歳）
├─ 段階2: 小3-4（8-10歳）
├─ 段階3: 小5-6（10-12歳）

├─ 見方・考え方（各教科の認知特性）
```

```
    ↓
発達段階に応じた最適化
    ↓
一人学び×協働の統合実践
```

**【原理2】診断と支援の統合**

```

```

## 3. 国語科

### 3.1 国語科の見方・考え方（DCS）

**国語科固有の認知構造**

```
【国語の見方・考え方】

「言葉による見方・考え方」
= 対象と言葉、言葉と言葉との関係を、
  言葉の意味、働き、使い方等に着目して捉え、
  その関係性を問い直して意味付けること

具体的要素:
├─ 音韻・文字レベル（音素、文字、表記）
├─ 語彙レベル（語の意味、語彙の広がり）
├─ 文法・統語レベル（文の構造、接続関係）
├─ 談話・文章レベル（段落構成、論理展開）
└─ 社会文化レベル（文化的文脈、読者との関係）
```

**認知科学的基盤**

- **音韻認識**: 音素の分解・統合能力
- **形態認識**: 文字認識、語形の認識
- **統語処理**: 文構造の解析
- **意味処理**: 語彙アクセス、意味統合
- **談話理解**: メンタルモデル構築、推論
- **メタ認知**: 理解のモニタリング、方略使用

**エビデンス**

- Perfetti, C. A. (1985). *Reading Ability*. Oxford University Press. → 語彙アクセスと理解の関係
- Kintsch, W. (1998). *Comprehension*. Cambridge University Press. → 談話理解の構造理論

### 3.2 国語科における8理論の統合マップ

```yaml
【T1: 資質・能力の3つの柱】
  知識・技能:
    - 音韻・文字の習得（小1-2）
    - 語彙の拡充（全段階）
    - 文法知識（小3以降）
    - 漢字・表記の習得
    
  思考・判断・表現:
    - 読解（情報の取り出し、解釈、評価）
    - 作文（構想、記述、推敲）
    - 話すこと・聞くこと（対話、発表）
    
  学びに向かう力:
    - 読書習慣
    - 言語感覚
    - 言語文化への関心

【T2: 自己調整学習】
  計画:
    - 読書計画（何を、どのように読むか）
    - 作文の構想（何を書くか、順序は）
    
  モニタリング:
    - 理解度のチェック（わからない語句、内容）
    - 表現の妥当性チェック
    
  方略:
    - 予測、要約、質問生成（読解方略）
    - プランニング、推敲（作文方略）
    
  振り返り:
    - 学習過程の省察
    - 次への改善点

【T3: 見方・考え方（DCS）】
  言葉の意味に着目:
    - 語の多義性
    - 文脈依存性
    
  言葉の働きに着目:
    - 接続詞の役割
    - 文末表現の効果
    
  言葉の使い方に着目:
    - 文体の選択
    - レトリックの活用

【T4: MI適性】
  言語的知能（優位）:
    - 語彙、文法への敏感性
    
  論理数学的知能:
    - 論理的文章構成
    
  対人的知能:
    - 対話、ディスカッション
    
  内省的知能:
    - 自己の感情・思考の言語化

【T5: 協働学習】
  読書会（文学的文章）:
    - 解釈の多様性の共有
    - 対話による理解の深化
    
  共同作文:
    - 役割分担（構想、下書き、推敲）
    
  ピア・レスポンス:
    - 作文の相互評価・助言

【T6: 社会とのつながり】
  実用的文章:
    - 手紙、メール
    - 報告書、説明文
    
  社会問題への言及:
    - 新聞記事、社説
    - 意見文

【T7: 認知負荷】
  内在的負荷:
    - 文章の難易度（語彙、文構造）
    
  外在的負荷:
    - 課題の複雑さ（同時処理の要求）
    
  本有的負荷:
    - スキーマ形成（文章構造の理解）

【T8: ZPD】
  現在の発達水準:
    - 独力で読める文章レベル
    
  最近接領域:
    - 支援があれば読める文章
    
  足場かけ:
    - 語句の説明、読解の観点提示
```

### 3.3 発達段階別設計

#### 【段階1】小学校1-2年（6-8歳）

**発達的特徴**

- **音韻認識**: 音素レベルの認識が発達
- **文字習得**: ひらがな→カタカナ→漢字（80字）
- **語彙**: 約5,000-8,000語（話し言葉）
- **文章理解**: 1-2文の短い文章、具体的内容

**8理論の重点**

| 理論 | 重点内容 |
|------|----------|
| T1 | ひらがな・カタカナの読み書き、短文の理解 |
| T2 | 「わからない」の認識、読み返す習慣 |
| T3 | 「つながる言葉」（接続詞）への気づき |
| T4 | 音声的アプローチ（音読、朗読）を重視 |
| T5 | ペアで音読、感想の簡単な共有 |
| T6 | 身近な生活（家族、友達）を題材に |
| T7 | 1文〜2文の短い文章、具体的挿絵 |
| T8 | 支援読み（教師と一緒に）から独力読みへ |

**学習活動例**

```
【単元例】「おはなしをたのしもう」（小1・5時間）

時1: 一人学び「絵本の読み聞かせ」
  - 教師の範読を聞く
  - 挿絵から内容を予測
  - 【診断ポイント】聞く態度、予測の妥当性

時2: 一人学び「音読練習」
  - 自分で音読してみる
  - わからない言葉に印
  - 【学習カード1】音読チェックカード
    ☑ すらすら読めた
    ☑ つまずいた言葉: [   ]

時3: 協働「ペア音読」
  - ペアで交代音読
  - 感想を一言ずつ
  - 【診断ポイント】協働態度、傾聴

時4: 一人学び「好きな場面を絵に」
  - 印象に残った場面を描く
  - 短い文で理由を書く
  - 【学習カード2】振り返りカード
    好きな場面: [   ]
    理由: [   ]

時5: 協働「絵の紹介」
  - グループで絵を見せ合う
  - 友達の絵から新しい発見
  - 【診断ポイント】表現力、対話
```

**ルーブリック（小1-2: 国語）**

- **語彙**: 書き言葉の拡充、抽象語彙
- **文章理解**: 論説文、複数テクストの比較

**8理論の重点**

### 5.1 理科の見方・考え方（DCS）

**理科固有の認知構造**

```
【理科の見方・考え方】

「理科の見方・考え方」
= 自然の事物・現象を、質的・量的な関係や時間的・空間的な関係などの
  科学的な視点で捉え、比較、関係付け、条件制御、推論などの
  科学的に探究する方法を用いて考えること

具体的要素:
├─ エネルギー領域（量的・関係的、時間的・空間的）
├─ 粒子領域（質的・実体的、量的・関係的）
├─ 生命領域（多様性・共通性、時間的・空間的）
└─ 地球領域（時間的・空間的、量的・関係的）
```

**認知科学的基盤**

- **観察**: 感覚情報の選択的注意
- **比較**: 類似性・差異性の認識
- **分類**: カテゴリー化
- **推論**: 仮説生成、演繹・帰納
- **モデル化**: 心的モデルの構築
- **実験的思考**: 変数制御、因果推論

**エビデンス**

- Driver, R., Squires, A., Rushworth, P., & Wood-Robinson, V. (1994). *Making Sense of Secondary Science*. Routledge. → 素朴概念と科学概念
- Osborne, J., & Dillon, J. (2008). *Science Education in Europe*. Nuffield Foundation. → 科学教育の効果的方法
