## 🎯 設計の特徴

### 1. 8理論の統合
各教科で以下の8理論がどのように現れるかを明示：
- T1: 資質・能力（3つの柱）
- T2: 自己調整学習
- T3: 見方・考え方（DCS）- 教科固有
- T4: MI適性
- T5: 協働学習
- T6: 社会とのつながり
- T7: 認知負荷理論
- T8: ZPD

### 2. 発達段階別設計
4段階の詳細設計：
- **段階1**: 小学校1-2年（6-8歳）
- **段階2**: 小学校3-4年（8-10歳）
- **段階3**: 小学校5-6年（10-12歳）
- **段階4**: 中学校1-3年（12-15歳）

### 3. 実践的要素
各教科ごとに以下を提供：
- **学習活動例**: 単元設計の具体例
- **学習カード**: 一人学び用の診断的カード（カード1〜55）
- **ルーブリック**: 4段階評価基準
- **教師用指導案テンプレート**: 実践的な授業設計枠組み
- **AI診断プロンプト**: Gemini統合用

### 4. 一人学び×協働の統合
- 個別最適化（一人学び、単元内自由進度学習）
- 協働学習（ペア、グループ、ディスカッション）
- 両者の効果的組み合わせ

### 5. エビデンスベース
認知科学・教育心理学の知見に基づく設計

## 🌟 ルーブリックの共通構造

### 4段階評価基準

| レベル | 名称 | 記号 | 説明 |
|--------|------|------|------|
| **4** | 到達・発展 | ⭐️⭐️⭐️⭐️ | 期待を大きく上回り、発展的な理解・創造を示す |
| **3** | 期待以上 | ⭐️⭐️⭐️ | 期待される水準を超えた理解・実践を示す |
| **2** | 期待水準 | ⭐️⭐️ | 学年相応の期待される水準に到達 |
| **1** | 要支援 | ⭐️ | 基礎的内容の理解に支援が必要 |

### 評価観点（教科横断）

すべての教科で以下の観点を含む：
1. **知識・技能**: 教科固有の知識・技能の習得
2. **思考・判断・表現**: 教科固有の思考力・表現力
3. **自己調整（T2）**: 学習の計画・モニタリング・振り返り
4. **協働（T5）**: 協働学習への参加・貢献

## 🔧 教師用指導案の共通構造

各教科の指導案テンプレートは以下の要素を含む：

```markdown
# [教科名] 指導案

## 単元名: [単元名]
## 学年: [学年]
## 時数: [時間数]

### 1. 単元の目標（8理論統合）
- T1〜T8の各理論の具体的目標

### 2. 単元の構成
- 時間配分、学習活動、形態（一人学び/協働）、学習カード、評価

### 3. 自由進度学習の運用
- 基本課題（全員到達）
- 発展課題（選択・挑戦）
- 進度管理

### 4. 評価計画
- 形成的評価
- 総括的評価

### 5. 配慮事項
- 個別支援
- ICT活用
```

## 🤖 AI診断プロンプトの共通構造

各教科のGemini AI診断プロンプトは以下を含む：

```yaml
システム指示:
  専門家としての役割設定

入力データ:
  - 学年
  - 学習カードの内容
  - 発達段階の情報
  - 教科固有の情報

分析観点:
  T1〜T8の各理論の評価観点

出力形式:
  1. 総合評価（4段階）
  2. 各理論の評価コメント
  3. 強み
  4. 改善点
  5. 次の学習カード提案

トーン:
  - 肯定的、励ます
  - 具体的、実行可能
  - 発達段階に応じた言葉遣い
```

## 🎓 使用方法

### 教師の方へ
1. **教科別設計の参照**: 担当教科のPartを参照
2. **指導案テンプレートの活用**: 単元設計の枠組みとして使用
3. **学習カードの活用**: 一人学び・自由進度学習で使用
4. **ルーブリックの活用**: 形成的評価・総括的評価で使用

### 研究者の方へ
1. **理論的基盤の確認**: 各教科の見方・考え方と8理論の統合
2. **実証研究の設計**: ルーブリックと評価指標を活用
3. **エビデンスの構築**: パイロット研究→RCTへの展開

### システム開発者の方へ
1. **データ構造の理解**: 学習カードの設計を参照
2. **AI診断の実装**: Geminiプロンプトを活用
3. **データベース設計**: Part 4の実装ガイドを参照（今後作成）
