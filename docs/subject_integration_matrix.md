## 1. マトリクスの構造と読み方

### 1.1 4軸×11教科の統合フレームワーク

```
                                4軸の統合
                                   │
        ┌──────────────────────────┼──────────────────────────┐
        │                          │                          │
   【軸1】3つの柱          【軸2】横断的基盤        【軸3】教科固有
   ・知識・技能            ・自己調整能力           ・見方・考え方
   ・思考・判断・表現      ・協働性                 ・中核的資質・能力
   ・学びに向かう力        ・社会接続               ・内容領域
                                   │
                                   │
                          【軸4】MI理論（8種の知能）
                          ・言語的・論理数学的・空間的・身体運動的
                          ・音楽的・対人的・内省的・博物的
                                   │
                                   ▼
        ┌──────────────────────────────────────────────┐
        │           11教科への展開                      │
        ├──────────────────────────────────────────────┤
        │  1. 国語     2. 社会     3. 算数・数学        │
        │  4. 理科     5. 音楽     6. 図工・美術        │
        │  7. 体育     8. 技術・家庭  9. 外国語         │
        │ 10. 道徳    11. 特別活動                      │
        └──────────────────────────────────────────────┘
```

### 1.2 マトリクスセルの読み方

各教科×各軸の交点には、以下の情報が含まれます：

```
┌────────────────────────────────────────┐
│  教科名：国語  ×  軸1：3つの柱         │
├────────────────────────────────────────┤
│                                        │
│  知識・技能:                           │
│    "語彙・漢字・文法の理解"            │
│    → 評価: 正確性、運用力              │
│                                        │
│  思考・判断・表現:                     │
│    "文章の要旨把握・論理的記述"        │
│    → 評価: 論理性、表現の工夫          │
│                                        │
│  学びに向かう力:                       │
│    "言葉への感性、読書習慣"            │
│    → 評価: 主体性、継続性              │
│                                        │
│  【診断問題例】                         │
│    新聞記事を書く課題で評価            │
│                                        │
│  【推奨学習活動】                       │
│    読書会、作文添削、漢字テスト        │
│                                        │
└────────────────────────────────────────┘
```
