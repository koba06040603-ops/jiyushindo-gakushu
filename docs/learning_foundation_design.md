### 1.2 なぜ「学びの土台」が必要か

| 従来の課題 | 学びの土台による解決 |
|-----------|-------------------|
| 知識を覚えても使えない | **自己調整能力**：学んだ知識をいつ・どう使うか判断できる |
| テストはできるが実社会で活用できない | **社会とのつながり**：学びと実生活・社会課題を結びつける |
| 一人では学べるが協働が苦手 | **主体性・協働性**：他者と建設的に対話し納得解を作る |
| 与えられた課題しかできない | **自己調整能力**：自ら課題を発見し学習方法を選択できる |
| 学ぶ意味が見出せない | **社会とのつながり**：学びが将来・社会に役立つ実感 |

**定義**: 自分の学習プロセスを意識的にモニタリングし、状況に応じて適切に調整する能力

**目標設定の階層構造**

```
長期目標（学期・学年）
    │
    ├─ "5年生の算数で平均80点以上を取る"
    │
    ▼
中期目標（単元・月）
    │
    ├─ "割り算の単元テストで90点以上"
    │
    ▼
短期目標（週・日）
    │
    ├─ "今週は余りのある割り算を完璧にする"
    │
    ▼
行動目標（具体的行動）
    │
    └─ "毎日、割り算の問題を10問解く"
```

### 2.4 自己調整能力の評価ルーブリック

| レベル | メタ認知 | 学習方略 | 目標設定 | 行動例 |
|--------|----------|----------|----------|--------|
| **1. 無自覚** | 理解度に気づかない | 単一の方法のみ | 目標を立てない | 「分からない」とも言えない |
| **2. 認識** | 「分からない」と言える | 教師の指示通りのみ | 他者から与えられた目標 | 「ここが分からない」と指摘 |
| **3. モニタリング** | 学習中に理解度確認 | 2-3の方法を使い分け | 自分で具体的目標設定 | チェックリストで自己点検 |
| **4. 調整** | つまずきに応じて修正 | 状況で最適な方法選択 | 進捗に応じて目標調整 | 「うまくいかないから別の方法」 |
| **5. 最適化** | 継続的に改善サイクル | 自分専用の方略創出 | 長期・短期目標を統合 | 学習ポートフォリオで自己分析 |

### 2.5 教科別の自己調整能力の現れ方

| 教科 | 自己調整の具体例 | 育成のポイント |
|------|-----------------|---------------|
| **国語** | 「読み方を変える」：分からない文章を音読→黙読→図式化と試す | 読解方略の引き出しを増やす |
| **算数・数学** | 「計算ミスのパターン発見」：間違いノートで傾向分析 | エラー分析と対策立案 |
| **理科** | 「実験の改善」：うまくいかなかった要因を考察し次回修正 | 試行錯誤のサイクル明示化 |
| **社会** | 「情報源の評価」：資料の信頼性を判断してから使用 | 批判的思考の習慣化 |
| **外国語** | 「自分の弱点把握」：文法は分かるがリスニングが苦手→対策 | 技能別の自己診断 |

## 3. 主体性・協働性の詳細設計

### 3.1 主体性・協働性とは

**定義**: 
- **主体性**: 自ら課題を見つけ、自ら考え、自ら判断し、行動する力
- **協働性**: 他者と対話し、多様な視点を統合して、共に納得解を作り出す力

### 3.2 対話的学習の構造

```

│     │ これらのスキルを明示的に教える            │         │

│     └─────────────────────────────────────┘         │
│                                                      │

│     └─────────────────────────────────────┘         │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 3.4 対話力の発達段階

| レベル | 段階名 | 対話の特徴 | 指導の重点 | 具体例 |
|--------|--------|-----------|-----------|--------|
| **1. 沈黙** | 非参加 | 発言しない、聞くだけ | 安心できる雰囲気づくり | 小声で「分からない」とつぶやく |
| **2. 応答** | 受動的参加 | 質問されれば答える | ペア対話から始める | 「どう思う？」に「うん」 |
| **3. 発信** | 自己主張 | 自分の意見を言う | 根拠を求める質問 | 「私は○○だと思います」 |
| **4. 対話** | 相互作用 | 他者の意見を聞き、比較・検討 | 「なぜ？」「例えば？」の問い | 「Aさんの意見と私のは違って...」 |
| **5. 促進** | 対話の調整 | グループ全体の理解を深める質問 | ファシリテーション技術 | 「みんなはどう考える？」 |

### 3.8 協働性の評価ルーブリック

| レベル | 参加態度 | 貢献 | 傾聴・対話 | 合意形成 |
|--------|---------|------|-----------|---------|

| **4. 調整** | 他者を巻き込む | 他者の強みを引き出す | 共通点・相違点を整理 | 対話で納得解を作る |
| **5. リード** | グループ全体を活性化 | 全員の力を最大化 | 深い理解を促す質問 | 全員が納得する統合案 |

## まとめ

本設計文書では、**学びの土台（横断的基盤）**を構成する3要素を詳細に定義しました：

1. **自己調整能力**: メタ認知、学習方略、目標設定を通じた自律的学習
2. **主体性・協働性**: 対話と協働を通じた深い学び
3. **社会とのつながり**: 地域、キャリア、SDGsを通じた学びの意味づけ

これらは相互に作用し合い、教科固有の資質・能力を支える基盤となります。

次のステップは、この基盤を全教科に統合した**統合マトリクス**の作成と、**継続的診断システム**の技術仕様設計です。
