# 画像ダウンロードが必要なスライドURL一覧

## 📥 ダウンロード手順

1. 下記のURLを**ブラウザで開く**（GenSparkにログインした状態で）
2. 画像が表示されたら**右クリック**→「名前を付けて画像を保存」
3. ファイル名は「slide_XX.png」の形式で保存（XXはスライド番号）
4. PowerPointファイルの該当スライドに画像を挿入

- PowerPointファイルには表紙とセパレータがあるため、実際のスライド番号は異なります
- スライド16 → PowerPointの20番目のスライド
- スライド31 → PowerPointの36番目のスライド
- など
